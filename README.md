# 🚀 DocTriage AI

> **Automated document classification, prioritization, and routing powered by Google Gemma.**  
> *Built for the ZeroDay OSS - Gemma Hack Day at IIIT Dharwad.*

---

## 💡 About the Project
Let’s be honest—sorting through endless piles of resumes, invoices, and support tickets manually is a massive bottleneck. We built **DocTriage AI** during the ZeroDay OSS - Gemma Hack Day[cite: 1, 14] to automate the chaos using Google Gemma, letting teams instantly classify, prioritize, and route documents with a single click.

---

## ✨ Key Features
* 📄 **Instant Ingestion:** Upload documents or paste raw text to be analyzed on the fly.
* 🤖 **Gemma-Powered Analysis:** Automatically categorizes document types and summarizes content.
* ⚡ **Priority Scoring:** Instantly flags high-urgency items so your team can act fast.
* 🖥️ **Lightweight Dashboard:** Clean, interactive UI built with Streamlit for seamless triage.

---

## 🛠️ Tech Stack
* **Frontend & UI:** Streamlit (Python)
* **AI Model:** Google Gemma (via Google GenAI SDK)
* **Text Processing:** Python PDF libraries (`pdfplumber` / `PyPDF2`)
* **Version Control:** Git & GitHub
